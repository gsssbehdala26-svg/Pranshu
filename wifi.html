Wi-Fi Password Safety Check

Check whether a password you choose for your own router meets basic strength guidelines. The check runs only in this browser; the password is not sent or saved.

Enter a password to see the check.

Secure your router

  • Use WPA3-Personal, or WPA2-AES if WPA3 is unavailable.
  • Choose a unique passphrase of at least 16 characters.
  • Change the router’s admin password and keep its firmware updated.
  • Disable WPS if you do not need it.

This is a basic guideline check, not a guarantee that a password is secure. Avoid entering a password currently in use if you do not want it visible on this screen.
